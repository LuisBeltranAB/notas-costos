## Estado de resultados absorbente
|     | Ventas                |                   |
| --- | --------------------- | ----------------- |
| -   | Costo de ventas       | Variables y fijos |
| =   | Utilidad bruta        |                   |
| -   | Gastos operativos     | Variables y fijos |
| =   | Utilidad de operación |                   |
Para calcular el coso de venta (cost of goods sold), se necesita calcular todos los gastos en los que se incurre al generar una unidad de producto.

Ahí se debe incluir:
- Mano de obra directa
- Materia prima directa
- Indirectos (máquinas, herramientas)

Por otra parte también hay gastos operativos, que no están relacionados al producto. Estos gastos incluyen:
- Supervisores
- Personal de mantenimiento
## Estado de resultados contribución marginal
|     | Ventas                  |
| --- | ----------------------- |
| -   | Costo variables totales |
| =   | Contribución marginal   |
| -   | Costos fijos totales    |
| =   | Utilidad de operación   |
Este proceso es el que utiliza la fórmula:
$$nS-nV-F=I$$
Para calcular el punto de equilibrio ([[Net profit]] = 0):
$$nS-nV-F=0$$

El apalancamiento operativo ([[Operating leverage]]) es convertir costos variables a costos fijos. Esto es más riesgoso ya que al bajar las ventas, se debe cubrir costos fijos, generalmente más altos.
