Cost function is a mathematical line function that models the behavior of costs.
$$y=a+bx$$
Where:
$$y=\textnormal{Total cost}$$
$$x=\textnormal{Activity level}$$
$$a=\textnormal{Total fixed cost}$$
$$b=\textnormal{Variable cost per unit}$$
I usually rewrite it as:
$$C(q)= F+Vq$$
We can use several methods to formulate the function such as:
- Least squares
- High-low
- Visual fit
